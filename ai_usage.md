# AI
In this project I'm using 2 AI tools, Claude Code and Google Antigravity. Why I'm using two tools is because Claude Code give better result on thinking when I need discuss about the architectural decisions, while Google Antigravity on generating codes. 

## What you used AI for
I'm use AI as a development assistant for basic coding tasks, such as generating boilerplate, writing unit-test cases. After AI generated code, I still review and validate by myself. 

## one place where AI helped you move faster
Generating boilerplate, like first time running project (generate scafolding based on my coding style), writing unitest, implement interface which build the scafolding of the function.

## one place where you disagreed with, corrected, or rejected AI output
It was, calling 3 object in one service that generated by AI. for optimization it should be using concurrent request so query to the database can run in concurrent without waiting other process to be finished first.

## what you would change about your AI workflow if you had to do this again
A better planning before execute the project. Involve AI as the design and validation phase not just the implementor. 

## how you verified the final implementation
I'm verified by running two step. Validation via unitest then manual testing through Postman/Bruno.
